# Task 2 — Restaurant Recommendation System

## Objective

Develop a content-based restaurant recommendation system based on user preferences.

## Approach

The system combines:

- Cuisine similarity
- City and locality similarity
- Price-range preference
- Restaurant rating
- Review-volume signal
- Table-booking preference
- Online-delivery preference

## Machine Learning Techniques

- TF-IDF Vectorization
- Cosine Similarity
- Feature normalization
- Preference-aware ranking

## Output

The system returns ranked restaurant recommendations with a match score and an explanation for the recommendation.

## Technologies

Python, Pandas, NumPy, Scikit-learn
