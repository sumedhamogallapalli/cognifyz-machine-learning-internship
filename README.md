# Cognifyz Technologies — Machine Learning Internship

This repository contains the machine learning projects completed during my Machine Learning Internship at Cognifyz Technologies.

## 🚀 Projects

### 1. Predict Restaurant Ratings

Built a regression model to predict restaurant aggregate ratings using restaurant, location, pricing, service, cuisine, and voting features.

**Approach:**
- Data preprocessing
- Feature engineering
- Leakage prevention
- CatBoost regression
- RMSE, MAE and R² evaluation
- Feature importance analysis

### 2. Restaurant Recommendation System

Developed a content-based restaurant recommendation system based on user preferences.

**Approach:**
- TF-IDF feature representation
- Cosine similarity
- Cuisine and location matching
- Price-range preference
- Rating and popularity signals
- Preference-aware ranking

### 3. Cuisine Classification

Developed a multiclass cuisine classification model.

**Approach:**
- Data preprocessing
- Primary cuisine extraction
- TF-IDF vectorization
- Logistic Regression
- Balanced class weights
- Accuracy, precision, recall and F1 evaluation
- Confusion-matrix analysis
